# Volvo GPS Guides — GitHub Pages site

Static website package with a searchable article index, 100 individual guide pages, a separate support page, shared styling, and SEO metadata.

## Files
- `index.html` — homepage and live article search
- `support.html` — separate support information page
- `articles/` — 100 individual HTML article pages
- `assets/style.css` — responsive site styling
- `sitemap.xml` — sitemap template
- `robots.txt` — crawler rules

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload the contents of this ZIP (upload the files and folders, not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose your main branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in Pages settings.

## Important
This is an independent informational resource, not an official Volvo Cars website. Verify vehicle-specific update steps against official Volvo documentation for the exact model, year, region, and navigation system. The articles are general guides and should be reviewed and expanded with model-specific authoritative details before publication.

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `sitemap.xml` and `robots.txt` after you know your GitHub Pages address.
